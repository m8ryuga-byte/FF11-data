# レジストハック(Immunobreak)

出典: [FF11 Again「第一回：レジストハックの超解説」](https://ff11again.com/immunobreak-explanation/)
(別セッションが収集し共有)。

## 概要

レジストハック(英: Immunobreak)とは、敵が持つ状態異常魔法への耐性ランクを、弱体魔法
(スリプル・パライズ等)を繰り返し当てることで段階的に引き下げ、最終的に弱体魔法が
通常命中するレベルまで下げるシステム。赤魔道士(RDM)にとって必須級の技術とされる。

## 耐性ランクの区分

| ランク | 特徴 |
|---|---|
| A+ / A | 魔法命中率をどれだけ積んでも無効(通常手段では弱体が通らない) |
| B+ / B / B- | 「精霊の印」等の特殊要素で対応する必要がある。ランクによって必要魔命が
  500近く変動する |
| C+ / C / C- | 装備・支援(バフ)の積み増しで現実的に弱体を通せる。レジストハックの
  主なターゲットとなる区分 |

レジストハックは、耐性ランクをより通しやすい区分(例: A+→C+)まで段階的に引き下げる
ことを狙う。

## 実例(記事内で紹介されたケース)

- 対象: Lv136 Locus系スケルトン(骨)の「スリプル」耐性
- 初期ランク: A+(通常は無効)
- 弱体魔法を複数回当て続けることで、耐性ランクを段階的にC+相当(約50%レジスト)まで
  低下させることに成功
- その状態で必要魔命1052を満たしたところ、通常命中でスリプルが成功した

## ハック確率を左右する要素

**重要**: レジストハックの成功確率は、詠唱者の「魔法命中(魔命)」ではなく
**弱体魔法スキル**にのみ依存する。魔命を積んでもハック確率自体は上がらない
(ハック成立後に弱体を「通す」ためには魔命が必要、という点と区別すること)。

ハック確率(=弱体スキル)を向上させる要素として記事内で挙げられているもの:

- 弱体魔法スキルブースト系の装備・アビリティ
- メリットポイント「ハック確率」への振り分け(5振り)
- レリック装束(RDM AF3/レリック系列)の「VIブーツ」
- サボトゥール(Saboteur、RDMのジョブアビリティ)発動中
- カイロンホーズ(装備): ハック効果を2段階分与える特殊効果を持つ

## 関連データ

弱体魔法を通すために必要な「魔命(魔法命中)」の目安値は
`data/mechanics/magic_accuracy_requirements.md` を参照。

BG-Wiki由来の魔法命中変換式(`data/combat_formulas.json` の
`magic_accuracy_formula`)では、命中率50%を境に魔命1あたりの命中率上昇幅が
半減する(50%以上: +1%/魔命、50%未満: +0.5%/魔命)という非線形の逓減が示されており、
耐性ランクが上がるほど必要魔命が急増するという本ページのロジックと整合する。
