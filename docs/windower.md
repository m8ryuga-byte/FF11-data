# Windower について(概要メモ)

## 注記(重要)

制限)で作成しているため、Claudeが持つ一般知識のみに基づく概要です。バージョン別の

## Windowerとは

Windower(ウィンドウワー)は、PC版『ファイナルファンタジーXI』のクライアントに対して
外部からフックし、UIの改善や便利機能を追加する非公式のサードパーティ製アドオン基盤。
「Windower 4」が長らく主流のバージョンとして使われている。

## 位置づけ・注意点

- Square Enix(SE)が公式にサポートしているツールではなく、利用規約(ユーザー同意事項)
  上グレーな位置づけとされる。アカウント停止等のリスクはユーザー自身の判断・自己責任。
- 一方で、コミュニティでは長年広く使われており、UI表示改善や情報表示の補助など、
  「プレイの快適化」目的での利用が中心。
- 自動化・連打・チート的な用途(RMT、無許可のBotなど)への利用は規約違反・不正行為に
  当たる可能性が高く、本データベースではそうした用途の具体的な実装支援は行わない。

## 主な構成要素(一般的に知られているもの)

- **Windower本体**: ゲームクライアントにフックし、ウィンドウのリサイズ・複数キャラの
  同時起動(マルチボックス)などを可能にする基盤。
- **プラグイン(Plugins)**: C++等で書かれた低レベル機能拡張。例: `Distance`(距離表示)、
  `Timestamp`(ログにタイムスタンプ付与)など。
- **アドオン(Addons)**: Lua言語で書かれた高レベル機能拡張。UI表示やヘルパー機能の
  実装に使われることが多い。代表例として挙げられることが多いもの:
  - `GearSwap`: ジョブごとの装備セットを条件に応じて自動的に切り替える(魔法詠唱時・
    WS発動時など)、著名なアドオンの一つ。
  - `Timers`/`TimerBar`: バフ・デバフ・リキャストの残り時間を表示。
  - `Ashita`(Windowerとは別系統の類似ツール): Windowerの代替として使われることがある。

## 導入の一般的な流れ(概要のみ)

1. 公式サイトからインストーラをダウンロードする。
2. FF11本体(POL/PlayOnlineまたはSquare Enix公式ランチャー経由)のインストール先を
   指定してセットアップする。
3. 必要なプラグイン・アドオンを `plugins`/`addons` フォルダに配置し、設定ファイル
   (`init.txt` 等)や `//lua load <addon名>` コマンドで読み込む。

具体的な最新のダウンロードURLやインストーラの詳細手順は、上記の理由により本メモには
含めていません。
