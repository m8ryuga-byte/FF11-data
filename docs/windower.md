# Windower について(概要メモ)

## 注記(重要)

このメモは、Windower本体のページ本文を直接取得できない環境(ネットワークプロキシの
制限)で作成しているため、大部分はClaudeが持つ一般知識のみに基づく概要です。
「基本的な使い方」セクションのみ、別セッションが収集した一次情報(Windower日本語Wiki
の本文)を反映した信頼度の高い内容です。それ以外(バージョン別の詳細な導入手順・最新の
アドオン一覧など)は未検証です。正確な最新情報が必要な場合は、公式サイト

共有してください。

## Windowerとは

Windower(ウィンドウワー)は、PC版『ファイナルファンタジーXI』のクライアントに対して
外部からフックし、UIの改善や便利機能を追加する非公式のサードパーティ製アドオン基盤。
「Windower 4」が長らく主流のバージョンとして使われている。

## 位置づけ・注意点

- Square Enix(SE)が公式にサポートしているツールではなく、利用規約(ユーザー同意事項)
  上グレーな位置づけとされる。アカウント停止等のリスクはユーザー自身の判断・自己責任。
- 一方で、コミュニティでは長年広く使われており、UI表示改善や情報表示の補助など、
  「プレイの快適化」目的での利用が中心。
- 自動化・連打・チート的な用途(RMT、無許可のBotなど)への利用は規約違反・不正行為に
  当たる可能性が高く、本データベースではそうした用途の具体的な実装支援は行わない。

## 公式サイト情報(別セッションが収集)

出典: [Windower公式サイト](https://www.windower.net/)(別セッションが収集し共有)。

- FF11用サードパーティ拡張ツールの現行版は「Windower 4」、確認された最新の安定版は
  **4.6**。
- 自動アップデート機能を持つ。
- `//video` コマンドでの動画録画機能を持つ。
- Luaによるオープンソースの拡張API(アドオン開発用)を提供。
- 開発者向けにIPC(プロセス間通信)対応がある。

## 主な構成要素(一般的に知られているもの)

- **Windower本体**: ゲームクライアントにフックし、ウィンドウのリサイズ・複数キャラの
  同時起動(マルチボックス)などを可能にする基盤。
- **プラグイン(Plugins)**: C++等で書かれた低レベル機能拡張。例: `Distance`(距離表示)、
  `Timestamp`(ログにタイムスタンプ付与)など。
- **アドオン(Addons)**: Lua言語で書かれた高レベル機能拡張。UI表示やヘルパー機能の
  実装に使われることが多い。代表例として挙げられることが多いもの:
  - `GearSwap`: ジョブごとの装備セットを条件に応じて自動的に切り替える(魔法詠唱時・
    WS発動時など)、著名なアドオンの一つ。
  - `Timers`/`TimerBar`: バフ・デバフ・リキャストの残り時間を表示。
  - `Ashita`(Windowerとは別系統の類似ツール): Windowerの代替として使われることがある。

## 導入の一般的な流れ(概要のみ)

1. 公式サイトからインストーラをダウンロードする。
2. FF11本体(POL/PlayOnlineまたはSquare Enix公式ランチャー経由)のインストール先を
   指定してセットアップする。
3. 必要なプラグイン・アドオンを `plugins`/`addons` フォルダに配置し、設定ファイル
   (`init.txt` 等)や `//lua load <addon名>` コマンドで読み込む。

具体的な最新のダウンロードURLやインストーラの詳細手順は、上記の理由により本メモには
含めていません。

## 基本的な使い方(Windower日本語Wikiより)

出典: [Windower 日本語Wiki「使い方の基本」](https://w.atwiki.jp/ff11windower2/pages/22.html)(別セッションが収集し共有)。

### マクロ(テキストスクリプト)

- マクロファイルは **ANSI(Shift-JIS)で保存する必要がある**。UTF-8で保存するとクラッシュする。
- `scripts` フォルダに配置する。
- `input /equip main ホフド` のようにFF11本体へコマンドを直接送信できる。
- 待機には `wait 10` を使う(FF11標準の `/wait` コマンドは使用不可)。
- 装備名に「ソ」「十」を含む場合、末尾に半角の円記号 `\` を付ける必要がある(FF11側の
  仕様に起因する文字化け対策と思われる)。

### 実行方法

| 実行元 | コマンド |
|---|---|
| チャットライン | `//exec ファイル名` |
| FFマクロ | `/console exec ファイル名` |
| Windowerコンソール | `exec ファイル名` |

### 自動実行

- `\scripts\autoload\autoload.txt` — Windower起動時に自動読込されるファイル。**編集禁止**。
- `\scripts\init.txt` — ユーザーが自由に編集できる、起動時自動実行用スクリプト。

### Luaマクロ・プラグイン・アドオン

- Luaマクロの実行: `lua e ファイル名`(拡張子なしで指定)。
- プラグイン(C++等の低レベル拡張)の読込/解除/再読込: `load` / `unload` / `reload` +
  プラグイン名。
- アドオン(Lua製の高レベル拡張)の読込/解除/再読込: `lua l` / `lua u` / `lua r` +
  アドオン名。格納先は `\addons\アドオン名\` フォルダ。
